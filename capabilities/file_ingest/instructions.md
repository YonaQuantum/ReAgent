# 文件解析指南

这是给模型读用户外部文件的辅助工具。用 `read_file` 读取本指南，按需使用。

## 何时使用

- 用户上传/提供了 PDF、图片等外部文件时，这些文件被放在工作区 `input/` 目录。
- 先 `list_files` 看 `input/` 下有哪些文件。
- PDF → `parse_pdf` 抽文字；图片 → `parse_image` 抽图中文字（OCR）。
- 纯文本文件直接用内置的 `read_file` 读即可。

## 注意

- 解析结果可能被截断（大文件），需要更多内容时提示用户或分段处理。
- OCR 依赖本机 tesseract；若未安装会返回可读错误，此时可提示用户安装。
