# 易拉宝设计指南

这是一份给模型看的打印设计指南。用 `read_file` 读取它，按下面的约束创作 HTML/CSS。

## 工作流

1. 用 `write_file` 在 workspace 里写 `index.html`（可再写 `style.css` 或内联 `<style>`）。
2. 调 `render_banner` 看预览和诊断。
3. 调 `lint_banner` 做客观检查（越界/字号/DPI）。
4. 有问题就改文件，再 render / lint，直到通过。
5. 调 `export_banner` 导出 PDF/PNG。

## 打印硬约束（必须满足）

- 画布是固定物理尺寸：默认 80cm × 200cm。用 CSS 的 `cm` 单位即可（浏览器按 96dpi 解析）。
- 主容器（如 `.banner`）的宽高必须正好等于画布尺寸，内容超出会被判为「越界」。
- 任何文字都不得小于 1cm（约 38px）。易拉宝是 2–3 米外阅读的远观物料，字号要给足：主标题 ≥ 3cm、小标题 ≥ 1.5cm、正文 ≥ 1.2cm、最小细节（注释/日期等）≥ 1cm。
- 正文、要点文字不要紧贴边缘，四周留出安全边距（约 3%）。
- 不要自己写 `@page`（导出时由工具注入，保证页面尺寸精确）。写了也会被覆盖。
- 图片若有，有效分辨率需 ≥ 150 DPI。

## 内容克制（可验证的硬约束）

- **删内容，不要缩字号。** 字号不达标时，验证器要求你删内容，而不是整体缩小。诊断里出现 `too_much_content` / `too_many_sections` / `too_many_cards` 时，就是内容太多，删。
- 全版中文正文不超过约 140 字；标题区块不超过 4 个；盒状「卡片」模块不超过 2 个。
- 必须有一个真正的主标题（≥ 3cm），不要所有文字一样大、平铺直叙——那是「拉伸的网页目录」的根源。

## 图标与装饰

- **不要用 emoji**（🎉📚☕ 这类字符显得廉价，像 AI 随手加的）。用 **SVG 线性图标**或纯排版代替。
- 图标用内联 `<svg>`（`viewBox="0 0 24 24"`、`stroke="currentColor"`、`fill="none"` 线性风格），或 `<img>` 引用真实矢量资源。避免任何 emoji 字符出现在正文、标题、列表里。

## 设计自由度（你完全自主）

- 构图：单列、分栏、全屏大图、极简留白……任意。
- 配色、字体、装饰、层级、文案、图标，全部由你决定。
- 可以只写一个 `index.html` 内联所有样式，也可以拆 `style.css`。
- `style`/`topic`/`copy` 等业务信息如果用户提到了，就体现在内容里，而不是当作死参数。
